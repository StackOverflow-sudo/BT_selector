# Results

This directory stores generated benchmark outputs.

Planned files:

- `bt_candidate_evaluations.csv`: one row per task, initial state, and candidate BT.
- `summary_by_selector.csv`: aggregate performance of random, rule-based, learned, and oracle selectors.
- `summary_by_task.csv`: aggregate performance by task.

Do not manually edit generated CSV files unless explicitly documenting a small debugging fixture.
